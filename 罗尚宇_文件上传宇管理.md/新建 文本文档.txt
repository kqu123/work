# 罗尚宇_文件上传与管理

本次作业旨在掌握 GitHub 网页端的基本操作，包括仓库的创建、文件的编辑以及本地文件的上传。以下是我的具体操作步骤说明：

## 任务一：在网页端创建并编辑 Markdown 文件

1. 在 GitHub 仓库主页，点击右上角的 **Add file** 按钮，在下拉菜单中选择 **Create new file**。
2. 在文件名输入框（Name your file...）中输入 `linux常用命令.md`。
3. 在下方的大文本框中，使用 Markdown 语法输入了常用的 Linux 命令及其功能说明。
4. 页面下滑，在 Commit new file 区域填写提交信息，并点击绿色的 **Commit new file** 按钮完成创建。

> **【![操作截图1](1.png)】**

*图1：在网页端编辑并提交 Linux 常用命令文档*

## 任务二：将本地作业文档上传至 GitHub

1. 准备好包含操作说明和截图的本地文档，命名为 `{你的姓名}_文件上传与管理.md`。
2. 回到 GitHub 仓库主页，点击 **Add file** 按钮，选择 **Upload files**。
3. 在弹出的页面中，将本地文档直接拖拽到虚线框内，或者点击 choose your files 选择本地文件。
4. 确认文件显示在列表中后，页面下滑，在 Commit changes 区域填写备注信息。
5. 点击绿色的 **Commit changes** 按钮，完成文件上传。

> **【![操作截图2](1.png)】**

*图2：在网页端上传本地作业文档*

## 总结
通过本次实验，我熟悉了 GitHub 网页端的界面布局，掌握了如何新建文件、编写 Markdown 文档，以及如何直接通过浏览器上传本地文件。GitHub 的版本控制系统对于代码和文档的管理非常高效。
